## Prompt

For question 1c, use the EQ Dataset.csv and estimate a first-order VAR as follows: 

Create a 3x1 vector of state variables z_t = [dg_t, re_t, dp_t]'. 

Create a VAR(1) process defined as z_{t+1} = gamma_0 + gamma z_t + e_{t+1}
Note that since the data set contains monthly values, t+1 represents 12 months after t. Regress z_{t+1} on an intercept and z_t for every starting month t such that an observation exists 12 months later. Make sure the dimensions for gamma_0 and gamma are 3x1 and 3x3 respectively. 

Let b_z = cov(dp_t, z_t)/ var(dp_t) where b_z is a 3x1 vector of beta coefficients from regressing dg_t, re_t, and dp_t onto dp_t. 

Let dp_bar = sample mean of dp in the EQ Dataset
Define kappa = 1/(1+exp(dp_bar))

For each horizon H = 1,..., 20:

b_t^(H) = (gamma - kappa^H gamma^{H+1}) (I - kappa gamma)^{-1} b_z

Define:
e_dg' = [1 0 0]
e_re' = [0 1 0]

Retrieve the long-run coefficients for each component:
b_re^(H) = e_re' b_t^(H)
b_dg^(H) = -e_dg' b_t^(H)
b_dp^(H) = 1- b_re^(H)-b_dg^(H)

Store b_re^(H), b_dg^(H), and b_dp^(H) for each horizon and verify that they sum to one at every horizon. Plot those coefficients against H horizons. Output should be code/1c_coeff.csv, code/1c.R, and figures/1c.png
