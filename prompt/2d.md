## Prompt

Let's work on question 2d. Use the EQ Dataset.csv. Note that since the data set contains monthly values, t+1 represents 12 months after t. We calculate the following variables:
xR_{e,t+1} = exp(re_{t+1}) - exp(rf_{t+1})
D_t/P_t = exp(dp_{t}) 

Let December 1940 be the start of the out-of-sample evaluation, meaning that we should use D/P from December 1939 to forecast the excess return in Decemeber 1940 as the first forecast. t is a monthly forecast origin with t+1 indicates the annual return 12 months later. moving month by month means increasing t by 1/12 of a year. 

For each forecast origin t, running OLS regression using only historical information about excess return and dividend-price ratio:

xR_{e,s+1} =  a_{t}^{OS} + b_{t}^{OS} * D_s/P_s + e_{s+1} such that s+1 less than and equal to t 

Construct the out-of-sample forecast, using estimated \hat{a_{OS}} and \hat{b_{OS}}:

\widehat{E}_t^{OS}[xR_{e,t+1}] = \hat{a_{t}^{OS}} + \hat{b_{t}^{OS}} * (D_t/P_t)

Simultaneously, at each forecast origin t, construct the historical expanding window mean of excess return observed by that time:
\overline{xR_{e,t}} = (1/N_t) * sum_{s+1 \leq t} xR_{e,s+1}

where N_t is the number of historical observations available at time t. \overline{xR_{e,t}} is used as a benchmark for xR_{e,t+1}. Move forward month by month, add newly completed dividend-price ratio & return to the expanding window sample, re-estimate \hat{a_{t}^{OS}} and \hat{b_{t}^{OS}}, update the historical mean, run the next out-of-sample regression, and repeat until the end of the sample.

Now, using all available observations in the full sample, run the OLS regression separately: 
xR_{e,s+1} = a_{IS} + b_{IS} * D_s/P_s + e_{s+1}

We retrieve \hat{a_{IS}} and \hat{b_{IS}} and construct the in-sample fitted value for every month starting from December 1940 to the end of the sample:

\widehat{E}_t^{IS}[xR_{e,t+1}] = \hat{a_{IS}} + \hat{b_{IS}} * (D_t/P_t)

For each month starting from December 1940 till the end of the period, store and plot \overline{xR_{e,t}}, \widehat{E}_t^{IS}[xR_{e,t+1}], \widehat{E}_t^{OS}[xR_{e,t+1}] using consistent format as in previous prompts. Save the plot as figures/2d_1.png. Store these values as well as corresponding xR_{e,t+1} in code/2d_1.csv. 

Next, we calculate the full-period out-of-sample R-squared as:
R_{OS}^2 = 1 - X/Y 
where X = sum_{t=1 to T} (xR{e,t+1} - \widehat{E}_t^{OS}[xR_{e,t+1}])^2
and Y = sum_{t=1 to T} (xR{e,t+1} - \overline{xR_{e,t}})^2

Finally, we calculate a rolling R_{OS}^2 using a 50-year rolling windown for forecasting errors. In particular, the first window covers from January 1941 to December 1990. Move the 50-year window by 1 month and repeat the process without re-estimating expanding window coefficients \hat{a_{t}^{OS}} and \hat{b_{t}^{OS}}. 

R_{Rolling OS}^2 = 1 - X/Y 
where X = sum_{s=t-50 to t} (xR{e,s+1} - \widehat{E}_s^{OS}[xR_{e,s+1}])^2
and Y = sum_{s=t-50 to t} (xR{e,s+1} - \overline{xR_{e,s}})^2

Plot R_{Rolling OS}^2 from December 1990 to the end of the sample. Save the plot as figures/2d_2.png and store the values in code/2d_2.csv
