## Prompt

Let's work on question 2d. Use the EQ Dataset.csv. Note that since the data set contains monthly values, t+1 represents 12 months after t. We calculate the following variables:
xR_{e,t+1} = exp(re_{t+1}) - exp(rf_{t+1})
D_t/P_t = exp(dp_{t}) 

## OS OLS
Let December 1940 be the start of the out-of-sample forecast, meaning that we should use D/P from December 1939 to forecast the excess return in Decemeber 1940 as the first forecast. 

For each forecast origin t, running OLS regression using an expanding window:

xR_{e,s+1} =  a_{t}^{OS} + b_{t}^{OS} * D_s/P_s + e_{s+1} such that s+1 less than and equal to t 

The first forecast uses all pairs of D_s/P_s and xR_{e,s+1} starting from December 1927 and December 1928 respectively and ending at November 1939 and November 1940 respectively. 

Using estimated \hat{a_{OS}} and \hat{b_{OS}}, estimate the out-of-sample forecast:

\widehat{E}_t^{OS}[xR_{e,t+1}] = \hat{a_{t}^{OS}} + \hat{b_{t}^{OS}} * (D_t/P_t)

Simultaneously, at each forecast origin t, construct the historical expanding window mean of excess return observed by that time:
\overline{xR_{e,t}} = (1/N_t) * sum_{i=1}^{N_t} xR_{e,i}

where N_t is the number of historical observations available at time t. The first mean uses xR_{e,i} from December 1928 to November 1940. 

Move forward month by month, add the next annual regression pairs, re-estimate \hat{a_{t}^{OS}} and \hat{b_{t}^{OS}}, update the expanding-window mean, run the next out-of-sample regression, and repeat until the end of the sample.

## IS OLS
In a separate OLS regression, using all available observations in the full sample:
xR_{e,s+1} = a_{IS} + b_{IS} * D_s/P_s + e_{s+1}

Using \hat{a_{IS}} and \hat{b_{IS}}, estimate the in-sample forecast: 

\widehat{E}_t^{IS}[xR_{e,t+1}] = \hat{a_{IS}} + \hat{b_{IS}} * (D_t/P_t)

## OS R-squared
Next, we calculate the full-period out-of-sample R-squared, using target months from December 1940 to December 2021:
R_{OS}^2 = 1 - X/Y 
where X = sum_{t=1}^{T} (xR{e,t+1} - \widehat{E}_t^{OS}[xR_{e,t+1}])^2
and Y = sum_{t=1}^{T} (xR{e,t+1} - [1/T * sum_{j=1}^{T} xR{e,j+1}])^2

Note: Don't adjust degrees of freedom (T-k) to compare the forecast errors between OS and the benchmark.
