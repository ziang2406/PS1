# Problem-set prompts

Store each problem-set prompt in this directory as a Markdown file.

Use the exact problem-set item as the filename, for example:

- `1a.md`
- `1b.md`
- `2a.md`

Suggested file format:

```markdown
# Problem 1a

## Prompt

Paste the prompt here.

## Notes

Add any relevant context or decisions here.
```
