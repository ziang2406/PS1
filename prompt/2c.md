Let's work on problem 2c. Using the same EQ Dataset.csv, apply the Amihud and Hurvich (2004) method. 

Note that since the data set contains monthly values, t+1 represents 12 months after t. We calculate the following variables:
xR_{e,t+1} = exp(re_{t+1}) - exp(rf_{t+1})
D_t/P_t = exp(dp_{t}) 

Estimate the AR(1) process: 
D_{t+1}/ P_{t+1} = theta + phi * D_t/P_t + u_{t+1}
Make sure to use only starting month t such that there is availably data 12 months later. Retrieve \hat{theta} and \hat{phi} 

Convert the dataset from months into correspoding years, denoting T as the total number of years in the dataset. In particular, T = nrow(EQ)/12. Calculate the bias-corrected slope estimate:
\hat{phi}^{c} = \hat{phi} + (1/T) * (1+ 3* \hat{phi}) + (1/T^2) * 3 * (1+ 3* \hat{phi})

Calculate the bias-corrected residual estimate: 
\hat{u}_{t+1}^{c} = D_{t+1}/ P_{t+1} - (\hat{theta} +  \hat{phi}^{c} * D_t/P_t)

Finally, control for u_{t+1} in the OLS regression:
xR_{e,t+1} = a + b * D_t/P_t + b_{u} * \hat{u}_{t+1}^{c} + e_{t+1}

Store the reported b as \hat{b}_{AH} and print the result in code/2c.csv. Output should also include code/2c.R.
